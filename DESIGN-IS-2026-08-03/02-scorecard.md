# Current Design Scorecard

1. Innovative — 2/3. The spend circuit-breaker concept is differentiated, but the surface uses familiar dashboard patterns.
2. Useful — 1/3. Core capabilities exist, but dashboard and judge journey are split and important behavior is local-state driven.
3. Aesthetic — 2/3. The dark semantic system is coherent, but inline literals and monolithic screens create inconsistency.
4. Understandable — 1/3. The judge path exists, but provider truth and simulated interactions are not consistently distinguished.
5. Unobtrusive — 2/3. Cards are restrained, though dense panels compete for attention.
6. Honest — 0/3. Hard-coded relevance and simulated provider outcomes can visually resemble verified provider evidence.
7. Long-lasting — 2/3. The industrial dark language is durable, with some trend-heavy neon styling.
8. Thorough — 1/3. Some focus and motion states exist; provider loading, unavailable, timeout, expiry, and persistence states are incomplete.
9. Environmentally friendly — 2/3. Reduced motion exists; measured JS/network evidence is unavailable.
10. As little design as possible — 1/3. Large monoliths, repeated markup, and competing demo surfaces add avoidable complexity.

Total: **14/30**
